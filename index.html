🚀 How to Publish / Host inFlow Premium

inFlow Premium is a production-ready Web ERP. You can run it on a Local Server (LAN) or host it on a Cloud VPS (Ubuntu, Windows Server, cPanel).

Option 1: Windows Server or Local LAN (Default)

Run the background server using the built-in production WSGI:

run.bat

The app will listen on port 5050. Any PC on the same Wi-Fi/LAN can access via http://[SERVER_IP]:5050.

Option 2: Cloud VPS with Nginx Reverse Proxy (Linux)

Configure Nginx to proxy port 80/443 to the Waitress WSGI server:

server {
    listen 80;
    server_name your-inflow-domain.com;
    location / {
        proxy_pass http://127.0.0.1:5050;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

Option 3: Web Hosting (cPanel / Apache)

Upload this index.html to your public_html/ directory. Visitors can use the Connect bar to link to your backend server or point directly to the application host.
