📋 How to set up Google Drive Direct Cloud API (3 Quick Steps)
  1. Go to Google Cloud Console → APIs & Services → Enable Google Drive API.
  2. In Credentials → Create Service Account → Click on the created account → Keys tab → Add Key → Create new key (JSON). Download the .json file.
  3. Open Google Drive, create a folder (e.g. inFlow Backups). Share that folder with your Service Account's email address (give Editor permission).
  4. Copy the Folder ID from the Google Drive URL (drive.google.com/drive/folders/[FOLDER_ID]), enter it below, upload or paste your Service Account JSON key, and click Test Connection!
